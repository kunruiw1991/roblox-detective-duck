# [UPDT🦆] Detective Duck

Authentic Roblox 3D mystery deduction & lock-cracking adventure inspired by **[UPDT🦆] Detective Duck** *(by Protocol: Anomaly)*.

**Live URL:** https://kunruiw1991.github.io/roblox-detective-duck/

## Features

- **Detective Duck Hero**: Low-poly green-headed Mallard Duck wearing a belted trenchcoat and jaunty black fedora with comical side-to-side waddling animation, webbed-foot *flap-flap-flap* SFX, bouncy jump, and a **QUACK!** button that makes suspects jump and shoots a golden sparkle trail straight toward your next clue.
- **Interactive 4-Digit Rotating Brass Padlock**: Kid-friendly giant tumbler dials (`>= 56px` touch arrows) with mechanical *click-clack* SFX, green digit match glow, optional **HINT** helper, orange `[X]` close button, and metallic *SNICK!* pop-open animation.
- **Authentic Roblox HUD**:
  - Top-left translucent topbar (`Cases`, `Wardrobe`, `Notebook`, `Accuse`, `Sound`, `★ Stars`).
  - Top-right pulsing red **Heartbeat Vital Monitor Badge** (`❤ PERMANENT / UNLIMITED`) with animated EKG waveform.
  - Bottom-left blue-and-white **Evidence Clue Log** toasts.
  - Bottom-center **Investigation Subtitle Box** with yellow **`SKIP`** button.
  - Visual 3-suspect **Accuse** cards with clue badges so young detectives (ages 5–6+) can solve cases visually without heavy reading.

## 3 Playable Mystery Cases

1. **Case 1 — The Penthouse Safe Heist**: Checkerboard marble floors, mahogany wood-panel walls, sliding framed floral painting hiding a cracked wall safe, flooded bathroom with a Plunger, dropped Room Key, muddy footprints, and brass padlock cabinet (`4-3-2-2`).
2. **Case 2 — Precinct Interrogation Room**: Atmospheric precinct room with a round wooden table under a hanging spotlight cone, detective Evidence Chalkboard, Janitor's Mop Bucket, potted fern, locked Evidence Locker (`7-1-5-9`), and *Tyler The Vandal* seated at the table.
3. **Case 3 — Jewelry Store Smash-and-Grab**: Plush red velvet carpets, shattered glass display cases, discarded Crowbar, Blue Paint footprints, padlocked Employee Security Door (`8-6-4-1`), and a **White Getaway Van crashed right through the rear brick wall** with flickering headlights!

## Controls

| Action | Desktop / Keyboard | iPad / Touch |
| :--- | :--- | :--- |
| Waddle / Move | `WASD` or Arrow Keys | Left translucent thumbstick |
| Camera Orbit / Zoom | Drag canvas / Mouse wheel | 1-finger drag / 2-finger pinch |
| Inspect / Talk / Unlock | `E` or click glowing clue/suspect | Tap clue directly OR right **`INSPECT / TALK / UNLOCK`** button |
| Jump | `Space` | Right **`JUMP`** button |
| Quack + Golden Clue Sparkles | `Q` | Right **`QUACK!`** button |
| Switch Case | `1`, `2`, `3` | Topbar **`Cases`** menu |
| Close Modal / Menu | `Esc` | Orange/Red **`X`** button |
